# Building a Web Site by converting the given figma design into html and css with responsiveness

### Prerequisites

*	PHP version 8.0
*	Bootstrap version 5.3
*	IDE - Sublime, Visual Studio Code

  ### Implementation

* Setup Server on computer depend on the OS (windows :xampp, wamp)
* Keep files on root folder and create index.php file inside the root folder
* Access the website through localhost ex : http://localhost/hs_lanka

  ### Deployment

  * Transfer file into server folder
  * Give file permission to images folders
  * Access the website through URL ex : http://domain_name/hs_lanka
